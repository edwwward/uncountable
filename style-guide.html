Uncountable 3.0 — Style Guide

Core Palette

Raw brand hues — fixed values that do not flip between themes. Reference by variable name, never by hex. Human names match DESIGN.md so both docs speak the same language.

Suite accents

One accent per product suite, used for the suite dot in the Solutions nav panel and suite-scoped highlights. Each suite reuses a Core Palette color rather than introducing a new one — Plum is the only addition, for Product Lifecycle. R&D is Emerald, Quality is Azure 700, and Innovation & PM is Amber.

Tints

Light washes for illustration fills and the mint/sky resource-card headers. Backgrounds and graphics only — never text.

Neutrals

The gray ramp flips with the theme: solid cool grays in light, white-alpha overlays in dark. Values below are live-resolved for the current theme.

Semantic Tokens

Flip between light and dark via [data-theme]. Always prefer these over raw brand colors for text and surfaces. Values below are live-resolved for the current theme.

Gradients

Fixed compositions — none flip with the theme except the hero wash. --grad-dark bands always carry a 1px --border-subtle hairline: the darkest stop is ~1.02:1 against the page and the band edge vanishes without it.

Typography

Poppins for display/heading/body, IBM Plex Mono for data. Only the 400 and 500 faces are loaded — 500 is this system's bold. Emphasize with size, color, or tracking, never with a heavier weight.

Spacing & Layout

4px base grid. Page content sits in a 1280px container (.container-max) with a clamp(20px, 3vw, 40px) gutter — the same container and gutter the Academy app uses.

Radii & Shadows

Radii stop at 12px — nothing pill-shaped except avatars and the tour play button. Shadows are navy-tinted in light, black-based in dark; --shadow-card adds a 1px inset top highlight.

Motion

One curve for everything: --ease-out: cubic-bezier(0.22, 1, 0.36, 1). Two durations: --dur-fast 140ms for hovers and toggles, --dur-base 220ms for entrances and slides. Never animate layout properties; disable entrances under prefers-reduced-motion.

Usage Rules

The rules that keep the palette accessible. Every ratio below is computed, not eyeballed — do the same before shipping a new pairing.

  • The Amber Rule. Amber is dark-surface only: 1.8:1 on white fails even the large-text bar. Chart thresholds, control-band markers, dark badges — never type on a light surface.
  • The Emerald rule. Emerald is for icons, fills, and graphical marks (≥3:1 non-text bar). The moment it renders as a character glyph, switch to a darkened text variant.
  • Azure has no headroom as text. 4.99:1 on white passes AA with almost nothing to spare — keep Azure text on white or lighter surfaces only, and never shrink it below 14px.
  • surface-dark is lifted. Dark cards use #0C1C63, not raw Midnight — Midnight is 1.08:1 against the dark page and reads as invisible.
  • 500 is bold. Only Poppins 400/500 are loaded. A heavier weight will silently render as faux-bold or fall back — cap everything at 500.
  • No colored accent stripes. Cards and callouts never get a colored side or top border. Use a tag, a tinted ground, or nothing.

Logo

White wordmark on dark chrome (nav, footer — rendered at 26px height). Navy monogram on light surfaces and as the favicon. Never recolor, never place the navy mark on a dark ground.

Buttons

CTA is Azure and darkens to --u-blue-700 on hover. Accent (Sky Cyan with Midnight text) is reserved for dark bands. Color/border fade over 220ms (--dur-base); any transform (e.g. a hover lift) runs at 140ms (--dur-fast) — the same split as every other hover state on the site.
